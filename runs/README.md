# Research runs

One folder per idea hunt, made by the `miccai-ideas` skill (`.claude/skills/miccai-ideas/`):
`plan.md`, `log.md`, `evidence-map.md`, `ideas/`, `decision-brief.md`. The log records every question,
tool call and decision, so a later reader or agent can follow and extend the reasoning.

Runs that reflect private research interests stay local; commit only the runs meant to be shared.
